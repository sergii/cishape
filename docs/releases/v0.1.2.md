# CIShape v0.1.2

CIShape v0.1.2 is a correctness patch for recommendation cost evidence.

## Fix

When the observed current runner shape is not present in CIShape's internal candidate cost catalog, CIShape no longer substitutes the recommended candidate's price as though it were the current runner's price.

Previously this could produce a fabricated savings value. A local `CPU10-MEM15` observation, for example, could report `-5.0%` solely because the default policy's 1.05 latency penalty was applied to a made-up current rate.

Now the CLI fails closed:

```text
estimated cost    unknown -> $... per p95 run
estimated saving  unknown (current runner rate unavailable)
```

The capacity recommendation remains available because CPU/RAM evidence is known; only the unsupported cost comparison is withheld.
