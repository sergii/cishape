# CIShape v0.1.1

CIShape v0.1.1 is a patch release that fixes the standalone Linux release package discovered during manual acceptance testing of v0.1.0.

## Fixes

- Include the complete `policies/` runtime data directory in the release archive.
- Include the complete `catalogs/` runtime data directory in the release archive.
- Make the published SHA-256 file portable by storing the archive basename instead of a build-time `dist/` path.
- Add release-gate acceptance coverage for the extracted-package flow:
  - `observe`
  - `report`
  - `profile`
  - `recommend`
  - `explain`
  - `advisory --format markdown`
  - `catalog`

## Why this patch exists

The v0.1.0 binary itself worked, including observation, local DuckDB history, profiling, and the synthetic demo. However, default advisory/recommendation commands expected repository-relative policy files that were not included in the published archive, and the checksum file referenced a build-directory path.

v0.1.1 fixes the distribution package without mutating the already published v0.1.0 tag or assets.
