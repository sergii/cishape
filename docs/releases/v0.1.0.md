# CIShape v0.1.0

CIShape v0.1.0 is the first public release of the local-first CI workload profiler and runner-shape optimizer.

## Highlights

- Observe real CI/local commands and store normalized run evidence locally in DuckDB.
- Build historical JobShape profiles from portable JSON/JSONL observations.
- Produce deterministic runner recommendations and Markdown/JSON advisory reports with explicit evidence thresholds and safety factors.
- Keep canonical CPU/RAM runner shapes separate from provider marketing labels.
- Map recommendations onto dated provider catalogs with explicit pricing/context provenance.
- Model queue, concurrency, cache state, billing increments, parallel batches, and workflow DAG economics.
- Collect read-only GitHub Actions capacity evidence with explicit repository/provider-account scope semantics and fail-closed completeness checks.
- Evaluate later observations against prior decisions without claiming causality from temporal correlation.
- Optionally compare deterministic feasible candidates with Jev in shadow mode; Jev cannot select outside the deterministic feasible set.
- Ship a Linux x86_64 release archive with checksum, provenance manifest, AGPL-3.0-only license, generated Cargo.lock, and third-party license notices.

## Safety boundaries

CIShape v0.1.0 is advisory-only. It does not rewrite `runs-on`, route jobs, mutate workflows, or require a CIShape SaaS backend.

Provider facts that cannot be proven are kept unknown rather than inferred. Contextual runner offers and capacity evidence fail closed when repository/account scope is missing or mismatched.

## License

CIShape is licensed under `AGPL-3.0-only`.

The binary archive also includes `THIRD_PARTY_LICENSES.html` generated from the release dependency graph.

## Platform

The published binary artifact in this release targets:

```text
x86_64-unknown-linux-gnu
```

Other platforms can still build from source, but v0.1.0 does not claim packaged binary support for them.

## Verify the binary archive

After downloading the archive and checksum:

```bash
sha256sum -c cishape-v0.1.0-x86_64-unknown-linux-gnu.tar.gz.sha256
tar -xzf cishape-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
./cishape-v0.1.0-x86_64-unknown-linux-gnu/cishape --help
```

The release provenance manifest records the exact source commit, workflow run, archive checksum, generated Cargo.lock checksum, project license, and license-notice checksums.
